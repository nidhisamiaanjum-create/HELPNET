## Items not classified as bugs

- The password-reset endpoint intentionally returns the same success response
  for unknown email addresses to prevent account enumeration.
- `common` has no separate feature by design/evidence.
- Cloudinary packages without configuration and manual backups are incomplete
  integrations/operations, not runtime failures of implemented features.
